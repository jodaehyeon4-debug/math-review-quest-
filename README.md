# 수학 복습 퀘스트

2학년 덧셈·뺄셈·곱셈 복습 도트 웹게임과 교사 기록장입니다.

- 학생(태블릿): 번호 선택 → 단원마다 몸풀기 4문제 → 도전 6문제 → 게임 7종 중 고르기
- 게임: 곱셈 던전(20층, 구구 펫 도감), 구구 짝꿍, 덧셈 레이스(질주), 합 블록, 개구리 수직선, 뺄셈 두더지, 셈 비
- 함께 들어 있는 기능: 이어하기, 문제 읽어 주기, 오늘의 미션·출석 도장, 복습 상자, 나의 성장 기록, 우리 반 보물상자
- 교사(PC): 학급 현황, 학생별 기록, 곱셈구구 지도, 집중 과제·목표 설정, CSV 내보내기 (초기 비밀번호 2106)

```bash
npm install && npm test   # 검사
npm start                 # http://localhost:5173
```

배포와 저장소 연결, 데이터 구조, 교사 기록장 개발 안내는 [docs/HANDOFF.md](docs/HANDOFF.md)에 있습니다.
